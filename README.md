# d27o — Software Engineer

Персональное портфолио: коммерческий опыт, инженерные практики и контакты.
Текущий стек: Vue 3, TypeScript, Pinia, Vitest, Playwright.

## Структура

- `pages/index.html` — проекты и архив ранних работ; адрес `/`.
- `pages/about.html` — опыт и позиционирование; адрес `/about/`.
- `pages/contact.html` — прямые контакты; адрес `/contact/`.
- `_config.yml` — общие метаданные, контакты, локация и текущий стек.
- `_includes/head.html` — метаданные страниц, canonical и карточки социальных сетей.
- `_scss/pages/career.scss` — оформление обновлённых страниц.

## Локальная проверка

Сайт использует существующий Jekyll / GitHub Pages и `Gemfile.lock`.
В совместимом Ruby-окружении:

```sh
bundle install
bundle exec jekyll build --strict_front_matter
bundle exec jekyll serve
```

Сборка и локальный сервер сами по себе не публикуют сайт.

## Публикация и конфиденциальность

Обновление 2026 подготовлено для проверки в отдельной ветке и draft PR.
Не сливать PR и не запускать публикацию до просмотра изменений владельцем.
Ветка master остаётся без изменений до слияния.

Описания коммерческой работы обобщены. Не добавлять названия закрытых
продуктов, заказчиков, исходный код, скриншоты, внутренние метрики и детали
реализации без разрешения на публикацию. Исторические должности не выводятся
из желаемой роли. Текущий стек не приписывается отдельным работодателям.
